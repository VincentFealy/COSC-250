# COSC-250: Microcomputer Organization

This repository contains laboratory exercises and circuit design projects completed for **COSC-250: Microcomputer Organization** at **Salisbury University**.

## Overview

This course focused on the organization and internal behavior of computer hardware. Coursework explored digital logic, Boolean algebra, switching networks, memory, registers, arithmetic logic units, and the fundamentals of processor architecture.

## Coursework

This repository includes:

- Digital logic and circuit design labs
- Register design and implementation
- Lab 9
- Lab 10
- Lab 11
- Lab 13
- Lab 14
- Calculator circuit project
- Computer organization and hardware design exercises

- Digital logic

- Logic gates

- Registers
